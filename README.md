# ODS Reserving Model

Materials accompanying the International Congress of Actuaries (ICA) 2026 presentation on the ODS Reserving Model.

## Overview

This repository provides the conference materials, references, and supporting resources used in the ICA 2026 presentation on the ODS Reserving Model.

The objective is to make the presentation content available to actuaries, data scientists, reserving practitioners, and researchers interested in modern approaches to reserve estimation and model-based reserving techniques.

## Repository Contents

- Presentation slides
- Technical notes
- Supporting examples
- References and further reading
- Supplementary conference material

## Intended Audience

This repository is intended for:

- Actuarial practitioners
- Reserving specialists
- Data scientists working in insurance
- Researchers and students interested in actuarial modelling
